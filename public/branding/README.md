# Branding assets

- `saudi-national-emblem.svg`: local copy of the Saudi national emblem (palm tree and crossed swords), sourced from Wikimedia Commons' public-domain file page: https://commons.wikimedia.org/wiki/File:Emblem_of_Saudi_Arabia.svg
- `madinah-horizon.svg`: original abstract line-art decoration for the Smart Inspector prototype. It is not an official regional emblem or logo.

The Smart Inspector interface is a hackathon prototype and does not claim government ownership or affiliation.
